# 따릉이 대여소 정보 (OA-13252)

대여소 마스터. **Open API가 아니라 파일(xlsx/csv) 데이터셋이다.**

- 데이터셋: [서울시 공공자전거 따릉이 대여소 정보](https://data.seoul.go.kr/dataList/OA-13252/F/1/datasetView.do)
- 제공: 서울특별시, 이용허락범위 제한 없음
- 인증키: 필요 없음 (파일 다운로드)

## 갱신 주기: 페이지 표기와 실제가 다르다

페이지의 "갱신주기"는 **실시간**이라고 적혀 있지만, 실제 파일은 **반기(6월·12월 기준)** 로 올라온다.

| 파일 | 게시일 |
|---|---|
| 26.6월 기준 | 2026-07-15 |
| 25.12월 기준 | 2026-01-13 |
| 25.6월 기준 | 2025-07-28 |
| 24.12월 기준 | 2025-01-16 |

따라서 **일 단위로 내려받아도 거의 매일 같은 파일**이다. 새 파일이 올라왔는지 확인하는 주기는 일 단위여도 되지만, 저장은 파일이 바뀌었을 때만 하는 쪽이 맞다.

## 다운로드

페이지의 `downloadFile(seq)` 함수가 폼을 POST하는 방식이다. 공식 API가 아니라 **페이지 구조에 의존하는 비공식 경로**라서 바뀌면 깨질 수 있다.

```
POST https://datafile.seoul.go.kr/bigfile/iot/inf/nio_download.do?&useCache=false
infId=OA-13252&seqNo=<seq>&seq=<seq>&infSeq=2
```

- `seq`는 파일마다 고유하다. 확인한 값: `24` = 26.6월 기준 xlsx (0.28MB), 11~17 = 2021~2022년 파일.
- `infSeq`가 틀리면(예: 1) HTML 오류 페이지(`잘못된 접근입니다`)가 200으로 온다. **HTTP 상태 코드로 성공을 판정할 수 없고** 내용(zip 시그니처 `PK`, `Content-Disposition`)을 확인해야 한다.
- 다운로드 성공 시 `Content-Type: application/x-msdownload`, 파일명이 `Content-Disposition`에 UTF-8로 온다.
- 최신 파일의 `seq`를 어떻게 알아내는지(목록 페이지 파싱)는 아직 구현하지 않았다.

## 파일 구조 (26.6월 기준 xlsx, 시트 `대여소현황`)

**헤더가 병합 셀로 여러 행에 걸쳐 있어서 pandas로 그대로 읽으면 컬럼이 깨진다.** 총 2,794행 중 위쪽 5행이 헤더이고 나머지 2,789행이 데이터다.

| B | 보관소(대여소)명 | 앞에 공백이 붙은 값이 있다 | ` 망원역 1번출구 앞` |
| C | 소재지: 자치구 | | `마포구` |

## 실시간 API와의 관계 (2026-11-24 검증)

실시간 API(`docs/sources/realtime-bikelist.md`)의 대여소 필드와 비교한 결과다.

1. **조인 키가 다르다.** 실시간 API의 `stationId`(`ST-4`)는 마스터에 없다. 대신 실시간 `stationName`이 **`"102. 망원역 1번출구 앞"`처럼 마스터의 대여소 번호를 접두로 달고 있다.** 마스터 `102`가 실시간 `ST-4`에 해당한다. 번호를 이름에서 파싱해 조인하게 된다.
2. **대여소 집합이 일치하지 않는다.** 실시간 2,744개, 마스터 2,789개. 번호 기준 교집합 2,728개, **실시간에만 16개, 마스터에만 61개.**
3. **교집합 중 이름이 다른 경우가 있다.** 번호가 같은 2,728개 중 공백 제거 후 이름까지 같은 것은 2,610개이고 118개는 다르다 (원인은 확인하지 않았다).
4. 같은 대여소에 대해 좌표는 일치한다 (`102`: `37.5556488` / `126.91062927`).
5. `stationId`와 대여소 번호의 대응이 시간이 지나도 고정인지는 **검증하지 않았다.**

## 미검증

- 목록 페이지에서 최신 `seq`를 자동으로 찾는 방법
- csv로 올라온 과거 파일(22.06월 기준 등)과 xlsx의 컬럼 일치 여부
- 마스터에만 있는 61개와 실시간에만 있는 16개의 성격 (폐쇄, 신설, 운영 중단 등)
- 이름 불일치 118건의 원인
